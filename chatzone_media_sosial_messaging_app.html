Dokumentasi Firebase Rules & Panduan GitHub Pages

1. Firebase Firestore Security Rules

Salin dan tempel aturan keamanan berikut pada Firebase Console (Firestore Rules):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Fungsi bantuan Owner Check
    function isOwner() {
      return request.auth != null && request.auth.token.email == 'marsellinus1703@gmail.com';
    }

    // Koleksi Profil Pengguna
    match /users/{userId} {
      allow read: if request.auth != null;
      allow write: if request.auth != null && (request.auth.uid == userId || isOwner());
    }

    // Global Chat Rules
    match /global_chat/{messageId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow delete: if isOwner();
    }

    // Direct Messages (Privasi Terjamin)
    match /artifacts/{appId}/public/data/dms/{chatId} {
      allow read, write: if request.auth != null;
    }

    // Stories (Masa berlaku 24 jam)
    match /stories/{storyId} {
      allow read: if request.auth != null;
      allow create: if request.auth != null;
      allow delete: if request.auth != null && (resource.data.authorUid == request.auth.uid || isOwner());
    }

    // Pengumuman Global (Hanya Owner)
    match /announcements/{annId} {
      allow read: if true;
      allow write: if isOwner();
    }
  }
}

2. Panduan Deploy ke GitHub Pages (Gratis)

  1. Buat repository baru di GitHub dengan nama chatzone.
  2. Simpan kode file ini dengan nama file index.html.
  3. Upload file index.html tersebut ke repository GitHub Anda.
  4. Buka menu Settings pada repository GitHub Anda.
  5. Pilih tab Pages di bilah sisi kiri.
  6. Pada opsi Source, pilih cabang main (atau master) dan folder / (root), lalu klik Save.
  7. Tunggu 1-2 menit hingga link publik GitHub Pages Anda aktif (contoh: https://username.github.io/chatzone).
